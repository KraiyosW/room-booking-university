# Room Booking Capstone Starter

Starter นี้ตั้งค่า Next.js, TypeScript, Tailwind และ Supabase packages ไว้แล้ว แต่ยังไม่มี schema, Auth หรือ business logic

## เริ่มต้น

```bash
npm install
cp .env.example .env.local
npm run dev
```

ก่อนให้ Codex implement ให้อ่าน `CAPSTONE.md`, เตรียม `AGENTS.md` และสร้าง plan ที่มี schema, routes, security และ test cases

ห้าม commit `.env.local` และห้ามใช้ Supabase secret/service-role key ใน client
